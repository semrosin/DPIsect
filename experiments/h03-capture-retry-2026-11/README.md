# H03: локальная проверка захвата

Статус: `confirmed` для локального контроля.

Один локальный ClientHello на `127.0.0.1:18443`; оба захвата — на `lo`.
Контроль проверяет приём, совпадение плановых байтов и штатное завершение
capture. Он не проверяет внешнюю сеть, физическую линию или независимые
точки наблюдения. Точные данные, бюджет и правило результата в `config.yaml`.
Идентификатор соответствует сохранённым конфигурации и метаданным запуска.

Пробу выполняет пользователь. Файлы PCAP и сырые журналы хранятся вне
git. Оба capture видят весь трафик `lo` во время опыта.
