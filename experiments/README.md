# Эксперименты

Каталоги сгруппированы по идентификатору вопроса и исследуемому сервису
или контрольной установке: `<question_id>/<series>/<experiment_id>/`.
Один сервис имеет один каталог; внутри находятся отдельные попытки.

Повторные попытки сохранены, если отличаются адресом, сетью, методом или
исходом: они не являются копиями одного измерения. Планы, отчёты и метаданные
каждой попытки находятся рядом. Сырые PCAP и журналы остаются в прежних
каталогах `artifacts/`, вне Git.

`run.json` сохраняет пути, записанные во время прогона: после переноса они
могут указывать на прежнее расположение конфигурации. Актуальные пути указаны
в отчётах; содержимое исторических `run.json` и планы не переписываются,
чтобы сохранить их контрольные суммы.
