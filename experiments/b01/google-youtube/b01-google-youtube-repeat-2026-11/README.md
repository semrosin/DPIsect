# B01 — повторный пилот без helper

Серия выполнена пользователем 18 ноября и остановлена на второй попытке;
статус — `inconclusive`. Не запускать повторно. Итоговое сопоставление с
предыдущими опытами — в [выводах этапа 2](../stage2-conclusion.md).

Одна серия содержит четыре подключения: Google → YouTube → YouTube → Google.
Параметры и ограничения — в [отчёте-плане](report.md), точная конфигурация —
в [config.yaml](config.yaml). Только пользователь запускает сетевую часть.

Серия уже выполнена пользователем 18 ноября и остановлена на второй
попытке; результат `inconclusive` записан в отчёте. Следующие команды
сохранены для описания подготовки и запуска, повторять `--run` нельзя.
Исходный манифест подготовленного пакета намеренно не обновляется после
заполнения отчёта; его хэш отчёта относится к версии до запуска.

Команды выполнять из корня репозитория обычным пользователем.

Подготовка без DNS-запросов и проб (сборка из локально доступного Go и кэша
зависимостей, создание расписания и контрольных сумм):

```bash
bash experiments/b01/google-youtube/b01-google-youtube-repeat-2026-11/run.sh --prepare
```

Подготовка уже выполнена агентом в текущем рабочем каталоге. На другом
компьютере её нужно выполнить заново. При отсутствии локального Go или
зависимостей команда завершится ошибкой без их автоматического скачивания.
Повторная подготовка не перезаписывает существующий каталог `prepared`.

Сетевая часть выполняется пользователем на исследуемом подключении, без VPN.
Пример для ранее использовавшегося WSL2-интерфейса `eth0`; если интерфейс
другой, заменить имя. Маршрут должен использовать указанный интерфейс:

```bash
bash experiments/b01/google-youtube/b01-google-youtube-repeat-2026-11/run.sh --run eth0
```

Эта команда проверит системный DNS, маршрут, MTU и offload, затем запустит
всю серию с клиентским capture. `sudo` используется только для настройки
offload и выдачи/снятия CAP_NET_RAW одному бинарю. Сам пробер работает от
обычного пользователя. Скрипту нужны `python3`, `ip`, `ethtool`, `getcap`,
`setcap`, `sudo` и стандартные утилиты оболочки. Если появился
`docs/DO_NOT_SCAN.md`, запуск остановится до проверки списка и пересмотра
плана. Если фиксированный адрес отсутствует в DNS, пришлите сохранённый
`dns.json`; автоматически менять адрес нельзя.

Остановка вручную — Ctrl+C. Скрипт восстанавливает исходные offload и снимает
capability при обычном выходе, SIGINT и SIGTERM. SIGKILL и выключение питания
не позволяют выполнить очистку; сохранённое состояние — в
`artifacts/b01-google-youtube-repeat-2026-11/offload-before.txt`.

В выполненной серии четыре основных offload восстановлены, но вложенный
`tx-tcp-mangleid-segmentation` изменился с `off` на `on`; текущая очистка
не восстанавливает вложенные параметры полностью. Для возврата этого
значения оператор выполняет:

```bash
sudo ethtool -K eth0 tx-tcp-mangleid-segmentation off
ethtool -k eth0 | grep -F 'tx-tcp-mangleid-segmentation:'
```

Если серия остановилась, не перезапускать её: сначала разобрать наблюдения.
Маркер `attempted` и существующие артефакты предотвращают повторный запуск.
Весь пакет прекращается при первом повторе TCP, ошибке capture или достижении
порога бюджета; незапущенные подключения не считаются измерениями.

После завершения вывести результаты без сетевых операций:

```bash
bash experiments/b01/google-youtube/b01-google-youtube-repeat-2026-11/run.sh --results
```

Пришлите этот вывод и ошибки скрипта. Для проверки байтов понадобится также
локальный `client.pcap`; он остаётся в игнорируемом git каталоге `artifacts/`.
`run.json` и план runner сохраняет рядом с конфигурацией. Статус отчёта
автоматически не меняется: итог ставится после разбора данных.
