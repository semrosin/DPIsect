# C01. Пилот на маршруте к Google

Четыре отдельные серии проведены без разбиения и с границей перед,
внутри и после SNI. Планы, журналы и метки исторических серий сохранены;
ошибка меток описана в errata отчётов. Итоги — в stage3-conclusion.md.

Для новой серии сначала подготовьте отдельную конфигурацию и правило
классификации, зафиксируйте их в Git и проверьте допустимость цели.
Точные случайные байты ClientHello runner сохраняет в plan.yaml после
подготовки TLS и до подключения. Если plan.yaml уже существует,
скрипт остановится, чтобы избежать перезаписи.

Оператор задаёт DPISECT_OPERATOR и запускает одну подготовленную серию:

```bash
DPISECT_OPERATOR=qjolk bash experiments/c01/google-youtube/run.sh \
  --confirm-target 142.251.155.119 c01-example-2026-11
```

Скрипт проверяет чистоту дерева, конфигурацию, сборку, маршрут и
Do Not Scan, запрашивает идентификатор серии и записывает подтверждение.
Он сохраняет и отключает offload, а после завершения восстанавливает
настройки и удаляет временный бинарь. Если восстановление не удалось или
процесс завершён SIGKILL, оператор выполняет:

```bash
bash experiments/c01/google-youtube/run.sh --restore
```

Монитор останавливает серию при повторе. Следующую серию автоматически
не запускают; наблюдения разбирают по PCAP. Выполненные серии повторно
не запускаются с прежними идентификаторами.

Для новых конфигураций используйте, например,
`paired_split: {control: 0, treatment: 117, first: treatment}`.
Параметр first задаёт вариант первой попытки. Отсутствие first сохраняет
исторический порядок и прежнюю интерпретацию сохранённых конфигураций.
