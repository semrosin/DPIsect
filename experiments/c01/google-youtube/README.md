# C01. Пилот на маршруте к Google

Две независимые серии используют профиль B01. Первая попытка серии split
планирует две записи с границей перед SNI. Первая попытка control пишет
ClientHello целиком. TLS-случайность отдельных сессий различается.

Пилот фиксирует наблюдения до остановки, но одной пары недостаточно для
оценки частоты и причины. Фактические границы и повторы проверяются по
PCAP. После остановки серии из-за повторов или аномалии дальнейшая отправка
требует оценки результата. Незапущенные попытки не являются измерениями.
