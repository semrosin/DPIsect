# C01. Пилот на маршруте к Google

Две независимые серии используют профиль B01. Первая попытка серии split
планирует две записи с границей перед SNI. Первая попытка control пишет
ClientHello целиком. TLS-случайность отдельных сессий различается.

Пилот фиксирует наблюдения до остановки, но одной пары недостаточно для
оценки частоты и причины. Фактические границы и повторы проверяются по
PCAP. После остановки серии из-за повторов или аномалии дальнейшая отправка
требует оценки результата. Незапущенные попытки не являются измерениями.

Для новой заранее подготовленной серии скрипт собирает пробер, показывает
маршрут и offload, выдаёт capability на время запуска и снимает её при
завершении. Параметр выбирает одну серию:

```bash
bash experiments/c01/google-youtube/run.sh split
```

Варианты control, inside и after выбираются аналогично. Смещения inside
и after равны 117 и 126, имя SNI занимает байты [110, 125). Скрипт прекращает работу при
ошибке пробера и не запускает следующую серию автоматически. Серии split и control уже выполнены, их данные не перезаписываются. Для повторов нужны новые
идентификаторы и заранее сохранённый план.
