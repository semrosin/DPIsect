# DPIsect
Активный пробер для исследования DPI: диагностика сбоев TLS/TCP, поиск триггеров фильтрации и локализация сетевого вмешательства.

Проект находится на исследовательском этапе; измерения из матрицы ещё не выполнены. Разработка планируется на Go с приоритетом Linux.
